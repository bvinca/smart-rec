## `job-be` — Mid-Level Backend Python Engineer
**Description**

We are hiring a backend engineer for our payments platform. You will design, build and maintain Python services that process thousands of transactions per minute, working closely with product and data teams. The stack is Python 3.11 with FastAPI, PostgreSQL, Redis, and Kubernetes on AWS. We deploy through GitHub Actions and use Terraform for infrastructure. The role suits someone who has shipped production REST APIs, cares about test coverage and observability, and is comfortable participating in on-call rotation.

**Requirements**

Required: 3+ years of professional Python development experience; production experience with FastAPI or Django REST Framework; strong SQL skills with PostgreSQL; Docker and at least one container orchestration platform (Kubernetes preferred); REST API design and OpenAPI; Git and pull-request review discipline; experience writing automated tests (pytest). Nice to have: AWS (ECS/EKS/RDS), Terraform, message queues (Kafka, RabbitMQ, SQS), Redis, observability stack (Prometheus, Grafana, Sentry). Bachelor's degree in Computer Science or equivalent industry experience.

## `job-da` — Data Analyst (Mid-Level)
**Description**

Join our analytics team as a data analyst supporting the commercial and operations functions. You will write SQL against our PostgreSQL warehouse, build dashboards in Tableau, and partner with stakeholders to turn business questions into data products. You will also run ad-hoc analyses in Python (pandas, scikit-learn) and present findings to non-technical audiences. The team is small and you should be comfortable owning a request from question to recommendation.

**Requirements**

Required: 3+ years in an analytical role; strong SQL (window functions, CTEs, query optimisation); Python with pandas and numpy for analysis; production experience with at least one BI tool (Tableau, Power BI, or Looker); demonstrable statistics background (hypothesis testing, regression); ability to communicate trade-offs to non-technical stakeholders. Nice to have: dbt, Airflow, Snowflake or BigQuery, A/B testing, basic machine learning (scikit-learn), Git. Bachelor's degree in a quantitative discipline (statistics, economics, computer science, engineering, mathematics) or equivalent.
